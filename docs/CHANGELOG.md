# 变更记录

本文件面向使用者，记录会影响安装、配置和使用方式的版本变化。
格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)。

## [未发布] - Obsidian 0.1.3 / Zotero 0.1.10

### 新增

- 新建 Obsidian 文献卡片时，可按 DOI 从 OpenAlex 提取作者所属机构，并通过人工覆盖表、Wikidata 或可选的 OpenAI-compatible 服务生成中文名称。
- 机构元数据和翻译结果使用本地缓存；网络异常、限流、无 DOI 或无机构时安全降级为“待填写”，不会影响卡片创建。
- 每篇新卡片只记录首次出现的第一单位；翻译即将降级为“待填写”时，可从既有文献卡片学习唯一一致的中文译名并写入人工映射表。

## [0.1.0] - 2026-08-14

### 新增

- 提供本地运行的 Zotero 批注同步服务，可将文字高亮和图片批注增量同步到 Obsidian Excalidraw。
- 支持在 Zotero 中为文献或 PDF 创建、打开并关联 Excalidraw 画布。
- 支持自动同步、手动同步、文献画布目录配置，以及同步状态查看。
- 支持从 Excalidraw 中回跳到对应的 Zotero 文献、PDF 页面和批注。
- 支持图片批注按 PDF 坐标在本地裁剪。

### 使用说明

- 同步只追加新的内容，不会覆盖用户在画布中编辑过的文字、位置或缩放。
- 已删除的 Zotero 源批注会在同步状态中标记为缺失，但不会删除画布内容。
- 未关联画布的批注会保留在待处理队列，待文献关联画布后继续处理。
